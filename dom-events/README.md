# DOM Events

This folder contains hands-on practice and mini projects focused on understanding how JavaScript handles browser events and user interactions.

It covers event listeners, event propagation, delegation, and real-time UI updates.

---

## 📚 Concepts Covered

### 🔹 Basic Events
- click
- dblclick
- input
- change
- keydown

### 🔹 Mouse Events
- mousemove
- hover effects
- custom cursor interactions

### 🔹 Advanced Event Concepts
- removeEventListener
- Event Object (`event`)
- `event.target`
- `event.data`
- Event Bubbling
- Event Delegation

---

## 🧩 Mini Projects Included
- Live Character Counter
- Custom File Upload
- Mouse Follower Effect

---

## 🎯 Learning Outcomes

Through these implementations, I gained a clear understanding of:

- How events propagate in the DOM
- How to manage dynamic UI updates
- How to optimize event handling using delegation
- Writing clean and modular event-based logic
